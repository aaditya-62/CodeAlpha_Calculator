# CodeAlpha Calculator

A simple, modern, and responsive calculator built with HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

The project provides a clean and easy-to-use calculator for performing everyday mathematical calculations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage/modulo operation
- Decimal number support
- AC button to clear the display
- DEL button to remove the last character
- Responsive design for mobile and desktop
- Basic error handling

## Technologies Used

- HTML5 — Structure of the calculator
- CSS3 — Styling, layout, and responsive design
- JavaScript — Calculator functionality and keyboard interaction

## How to Run

No installation or additional software is required.

### Run Locally

- Download or clone this repository.
- Open the project folder.
- Open index.html in a web browser.
- The calculator will start running.

### Using a Code Editor

Open the project folder in a code editor such as Visual Studio Code and open index.html in your browser.

## Keyboard Controls
| Key	| Action |
|---|---|

| + | Addition |
| - |	Subtraction |
| *	| Multiplication |
| /	| Division |
| %	| Modulo |
